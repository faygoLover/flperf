# faygoLover's Performance (flperf)

Производительность и стабильность сборки S5 в одном моде. Ставится и на сервер, и игрокам; работает и с одной стороны.
Каждая правка включается отдельно в `config/flperf-mixins.properties` (после перезапуска), числа — в `flperf-common.toml` и `flperf-client.toml`.

| Правка | Где | Что делает | Заменяет |
|---|---|---|---|
| `warm_chunks` | сервер | чанки, которые сервер отправляет игрокам, греются; самые тёплые (до 400) держатся загруженными без тиков, прогреваются при старте; остывание вдвое за 2 ч игрового времени. `/flperf warm [here\|clear]` | Better Chunk Loading (убран: невидимые чанки после телепорта) |
| `tick_guard` | оба | сбой в тике сущности, блок-сущности, блока, предмета — заморозка вместо падения; игрока — отключение. Админам сообщение. `/flperf frozen [resume\|kill N]` | Neruina (идея) |
| `advancements` | оба | достижения по белому списку (`rpmedicine:book/*` + родители), без окна и уведомлений | — |
| `sync_loads` | сервер | пчёлы, пути, карты, лучи, сон, скалк, клады не грузят чанк синхронно | ServerCore (идея) |
| `despawn` | сервер | подобранный предмет не делает моба вечным, при исчезновении роняет подобранное | Let Me Despawn (идея) |
| `distance` | клиент | дальность эллипсом (по вертикали ×2, по бокам ×1.1), для чанков (Embeddium) и сущностей | betterfpsdist |
| `terrablender` | сервер | правила поверхности: отсечение биомов, которых нет рядом; одна последовательность правил TerraBlender | TerraBlenderFix |
| `safety` | оба | битая сущность при загрузке не роняет сервер; сущности из чужих потоков — в очередь; ошибки команд в лог | Cupboard |
| `structures` | сервер | пределы поиска структур (радиус, 50 с), карты 40 чанков, /locate 110; падение фичи не роняет генерацию; структуры не ближе 32 блоков | structureessentials |
| `recipebook` | оба | книга рецептов выключена | recipeessentials |
| `gpu_leak` | клиент | видеопамять забытых буферов освобождается (Cleaner) | Gpu memory leak fix |
| `mcreator` | оба | моды MCreator не создают объект переменных игрока на каждое обращение | MCreator Mem Fix |
| `async_save` | сервер | SavedData и level.dat пишутся в фоне атомарно; при остановке ждём запись | fastasyncworldsave |
| `atlas_pack` | клиент | встроенный обязательный ресурспак: Tobacconist, Superb Warfare, `peace`, иконка двери G3 уменьшены → атлас 8192² | — |

Разбор исходных модов: `Claude Code/Pack Audit/briefs/flperf_analysis.md`.

Сборка: JDK 17, `gradlew.bat build` → `build/libs/flperf-<версия>.jar` (MixinExtras внутри, jarJar).
Для компиляции нужны jar в `libs/` (в .gitignore): `embeddium-0.3.31+mc1.20.1.jar`, `TerraBlender-forge-1.20.1-3.0.1.10.jar`.
